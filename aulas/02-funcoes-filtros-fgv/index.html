Revisão Rápida + A Pegadinha dos Colchetes

Uma diferença simples entre R e Python que a FGV adora explorar em prova:

Em R (Correto)

Criar vetor usa c( )

# c() CRIA o vetor frutas <- c("manga", "banana", "pera", "laranja") frutas

Colchetes [ ] em R servem para pegar elementos dentro do vetor!

Pegadinha de Prova (Errado em R!)

Usar [ ] para criar vetor dá ERRO

# Isso e sintaxe de Python, NAO funciona em R: frutas <- ["manga", "banana", "pera", "laranja"] # Erro: '[' inesperado

Só com essa regra você já elimina 3 alternativas da Q76 da Receita Federal!

1. Indexação com Colchetes [ ]

Em R, cada elemento de um vetor tem um número de posição — e a contagem sempre começa no 1.

Visualizando as posições de frutas

Posição [1]
"manga"
Posição [2]
"banana"
Posição [3]
"pera"
Posição [4]
"laranja"

Teste no RStudio

frutas <- c("manga", "banana", "pera", "laranja") frutas[1] # "manga" frutas[3] # "pera" frutas[c(1, 2, 4)] # "manga" "banana" "laranja"

O pulo do gato

  • Você pode passar um número (frutas[1]) ou um vetor de posições (frutas[c(1, 2, 4)]).
  • Atenção: em Python o primeiro item é 0; em R é 1!
  • Índice negativo em R (frutas[-3]) remove aquela posição!
Exercício relâmpago: Pergunte o que sai em frutas[c(2, 4)] antes de ela rodar.
Filtros de Texto no R Base

2. Buscando Palavras com grep()

A função grep(padrao, vetor) procura um texto dentro de cada item e devolve as posições onde encontrou.

Passo a passo (como o R pensa)

palavras <- c("manga", "banana", "pera", "laranja") # Passo 1: quais posicoes contem a letra "n"? grep("n", palavras) # Saida: [1] 1 2 4 # Passo 2: usar essas posicoes dentro de [ ] palavras[grep("n", palavras)] # Saida: [1] "manga" "banana" "laranja"

Lendo de dentro para fora

  1. grep("n", palavras) devolve 1, 2, 4 (porque "pera" não tem "n").
  2. Então palavras[grep("n", palavras)] vira exatamente palavras[c(1, 2, 4)]!
  3. Cuidado na ordem dos argumentos: primeiro o que você procura ("n"), depois onde procurar (palavras).
Teste ao vivo: Peça para ela trocar "n" por "r" (palavras[grep("r", palavras)]) e prever que vai sair "pera" "laranja".

3. Tomando Decisões com if / else

Para o programa escolher entre dois caminhos, usamos uma condição lógica entre parênteses ( ) e blocos entre chaves { }.

Operadores de comparação

  • > maior que  |  < menor que
  • >= maior ou igual  |  <= menor ou igual
  • == igual a (dois sinais de igual!)
  • != diferente de

O resultado de uma comparação é sempre TRUE ou FALSE.

Estrutura em R (teste mudando a nota!)

nota <- 8 if (nota >= 7) { print("Aprovada") } else { print("Revisar") }

Repare: o else fica na mesma linha do } que fecha o if.

Dica: Peça para ela testar com nota <- 5 também. Isso prepara diretamente o terreno para o if (param > -3) { ... } else { return(0) } da questão de Analista-Tributário!
R4DS • Cap. 25 (Funções) & PDF Estratégia pág. 133

4. Criando Suas Próprias Funções em R

Assim como guardamos números com <-, em R também guardamos uma função dentro de um nome usando <- function(...).

Molde oficial (caiu nas 2 provas!)

nome_funcao <- function(arg1, arg2) { # comandos que a funcao executa resultado <- arg1 + arg2 return(resultado) # opcional! }
Regras de Ouro FGV

4 pontos que matam questões

  • Em R usa-se <- function(...) — NUNCA def (que é Python).
  • Os argumentos não levam tipo (nada de lista:list).
  • O corpo fica entre chaves { }.
  • return() é opcional: sem ele, a função retorna automaticamente a última expressão avaliada!
Reforce a regra 4: Na questão de Analista-Tributário 2023, o bloco if termina em print(temp) sem return() — em R, print(temp) imprime e também devolve o valor de temp!
Prática Guiada • 10 minutos

Mão na Massa: Criando 2 Funções no RStudio

Digite, rode a definição com Ctrl + Enter (veja aparecer em Functions no Environment) e depois chame a função!

Função 1 — Com return()

dobro <- function(x) { return(x * 2) } dobro(15) dobro(c(2, 5, 10))

Função 2 — Com if / else (retorno implícito)

situacao <- function(nota) { if (nota >= 7) { "Aprovada" } else { "Revisar" } } situacao(8) situacao(5)
Atenção no Environment: Mostre que primeiro definimos a receita (dobro aparece na aba Environment → Functions), e só quando chamamos dobro(15) é que ela executa de verdade.
Questão Real #1 • Auditor-Fiscal RFB 2023 (FGV — Q76)

Qual código exibe "manga" "banana" "laranja"?

Tente eliminar as alternativas olhando apenas a sintaxe de R que acabamos de aprender:

  • A) def search_string as function (lista, palavra){ return(list of[grep(palavra, lista)]) }  |  palavras <- ["manga", ...]
  • B) search_string <- function(lista:list, palavra:string){ return(list of[grep(palavra, lista)]) }  |  palavras <- ["manga", ...]
  • C) search_string <- function(lista, palavra){ return(lista[grep(palavra, lista)]) }  |  palavras <- ["manga", "banana", "pera", "laranja"]
  • D) search_string <- function(lista, palavra){ return(lista[grep(palavra, lista)]) }  |  palavras <- c("manga", "banana", "pera", "laranja")
  • E) def search_string as function(lista, palavra){ return(list of[grep(palavra, lista)]) }  |  palavras <- a("manga", ...)
Gabarito: D
• A e E (erradas): usam def ... as function (não existe em R), list of[...] e a(...).
• B (errada): usa tipagem lista:list, palavra:string, list of[...] e colchetes [...] para criar vetor.
• C (errada): quase certa, mas cria o vetor com [...] em vez de c(...).
• D (correta): declara com <- function(...), filtra com lista[grep(palavra, lista)] e cria o vetor com c(...)!
Condução: Peça para ela apontar o erro de cada letra (A, B, C, E) antes de clicar em revelar. Depois rode a letra D no RStudio!
Aquecimento para a Questão #2

O Que É Recursão? (Sem Mistério)

Recursão é simplesmente uma função que chama a si mesma com um valor menor até bater em uma condição de parada.

Exemplo mini (antes do lista(15))

lista <- function(param) { if (param > -3) { temp <- param + lista(param - 3) print(temp) } else { return(0) } } lista(6)

Pense como uma escada (Ida e Volta)

  1. Ida (descendo): lista(6) precisa de lista(3), que precisa de lista(0), que precisa de lista(-3).
  2. Parada: -3 > -3 é FALSE! Cai no else e devolve 0.
  3. Volta (subindo e imprimindo):
    • lista(0): 0 + 0 = 0 → imprime 0
    • lista(3): 3 + 0 = 3 → imprime 3
    • lista(6): 6 + 3 = 9 → imprime 9
Ponto crucial: Destaque que o print(temp) só roda depois que a chamada de dentro terminar! Por isso o menor número (0) é impresso primeiro.
Questão Real #2 • Analista-Tributário RFB 2023 (FGV)

Qual a ordem dos valores exibidos por lista(15)?

Use a mesma lógica de ida e volta para rastrear a chamada real da prova:

Código da Prova (ATRFB 2023)

lista <- function(param) { if (param > -3) { temp <- param + lista(param - 3) print(temp) } else { return(0) } } lista(15)
Ordem exibida no Console:
0, 3, 9, 18, 30, 45
Pegadinha clássica: marcar 45 → 0 ao contrário! Como o print(temp) vem depois da recursão, ele imprime no retorno (de baixo para cima).
