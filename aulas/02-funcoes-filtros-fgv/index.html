1. Tabelas no R: data.frame e tibble

Uma tabela no R junta vários vetores do mesmo tamanho lado a lado — exatamente como uma planilha ou tabela de Banco de Dados.

Criando nossa 1ª tabela (sem instalar pacotes!)

notas_rfb <- data.frame( materia = c("Portugues", "Estatistica", "Fluencia", "Tributario"), acertos = c(8, 5, 9, 7), total = c(10, 6, 10, 10) ) notas_rfb str(notas_rfb) summary(notas_rfb)

Conceitos do R4DS para gravar

  • Linha = uma observação (registro).
  • Coluna = uma variável (cada coluna é um vetor c()).
  • data.frame é a tabela padrão do R base.
  • tibble (que aparece no Cap. 3 do R4DS) é uma versão moderna do data.frame que imprime mais bonito no console e mostra o tipo de cada coluna (chr, dbl, int).
  • View(notas_rfb) abre a tabela igual Excel no RStudio!
Prática: Peça para ela rodar notas_rfb e clicar no objeto notas_rfb lá no painel Environment (abre a aba estilo Excel automaticamente).

2. Selecionando Colunas e Filtrando Linhas

No R base (o que mais aparece em enunciados curtos de concurso), usamos $ e [linha, coluna].

Teste no RStudio

# Pegar uma coluna como vetor usando $ notas_rfb$acertos mean(notas_rfb$acertos) # Acessar por [linha, coluna] (vazio = todas) notas_rfb[1, ] # 1a linha inteira notas_rfb[, "materia"] # coluna materia # Filtrar linhas com condicao logica notas_rfb[notas_rfb$acertos >= 8, ] subset(notas_rfb, acertos >= 8)

Regra de ouro dos colchetes em tabela

tabela[ LINHAS , COLUNAS ]
  • Antes da vírgula: quais linhas você quer.
  • Depois da vírgula: quais colunas você quer.
  • Deixou em branco? Significa "traga todas"!
  • Cifrao $: extrai a coluna inteira como vetor para passar direto em mean(), sum(), sd().
Pergunta rápida: "Se eu quiser apenas a coluna materia das matérias com acertos >= 8, o que coloco depois da vírgula?" → notas_rfb[notas_rfb$acertos >= 8, "materia"].

4. Revisão Rápida: if / else e function()

Para resolver a outra questão real de R da RFB 2023 (Analista-Tributário), precisamos só destes 2 blocos:

Molde de Função + if / else

situacao <- function(nota) { if (nota >= 7) { "Aprovada" } else { "Revisar" } } situacao(8) situacao(5)
Detalhe Crucial do R

O retorno implícito

  • Em R, o return() é opcional (como lembra o seu PDF na pág. 133).
  • Sem return(), a função devolve automaticamente o resultado da última expressão avaliada.
  • E atenção: print(temp) imprime na tela E também devolve temp!
Prática: Peça para ela rodar situacao(8) e situacao(5) no RStudio antes de irmos para o aquecimento de recursão.
Aquecimento • Antes da Questão de Analista-Tributário

Entendendo Recursão em 3 Passos

Recursão é uma função que chama a si mesma diminuindo o número até bater no freio (else return(0)).

Versão reduzida: lista(6)

lista <- function(param) { if (param > -3) { temp <- param + lista(param - 3) print(temp) } else { return(0) } } lista(6)

Pense como uma escada (Ida e Volta)

  1. Ida (descendo de 3 em 3):
    lista(6) → lista(3) → lista(0) → lista(-3).
  2. Freio (caso base):
    -3 > -3 é FALSE → entra no else e retorna 0.
  3. Volta (somando e imprimindo):
    • lista(0): 0 + 0 = 0 → imprime 0
    • lista(3): 3 + 0 = 3 → imprime 3
    • lista(6): 6 + 3 = 9 → imprime 9
Ponto-chave: Como print(temp) está depois da chamada lista(param - 3), ele só imprime na volta — por isso sai 0, 3, 9 e não 9, 3, 0.

Lógica de 3 Estados: ? (SQL) = NA (R)

A Q80 do seu PDF cobrou lógica de 3 estados (T, F, ?) em SQL — e no R o valor desconhecido NA funciona exatamente igual!

Rodando a Q80 de SQL direto no R!

# Em R: | = OR, & = AND, ! = NOT, NA = unknown (?) # I. (T OR F) AND (? OR T) (TRUE | FALSE) & (NA | TRUE) # II. T AND ((? OR F) OR ?) TRUE & ((NA | FALSE) | NA) # III. NOT (? AND (? AND ?)) !(NA & (NA & NA))
Saídas no R: Item I → TRUE  |  Item II → NA  |  Item III → NA.
Gabarito da Q80 (pág. 140): D (II e III, apenas)!

Por que NA | TRUE dá TRUE?

  • No OU (|), basta um lado ser verdadeiro para o resultado já ser TRUE — nem importa o que está escondido no NA!
  • Já no E (&), se um lado é TRUE e o outro é NA, não dá para saber → continua NA.
  • Esse mesmo conceito está no Capítulo 12 (Vetores lógicos) do R4DS!
Por que mostrar isso? Conecta duas matérias de uma vez: ela entende o NA do R4DS Cap. 12 e já fixa a Q80 do PDF da Receita Federal!
