3. Os Verbos do dplyr + Pipe |> (Ponte com SQL)

      
No Capítulo 3 do R4DS, o livro usa verbos bem legíveis — que fazem ponte direta com SQL!


      

        

          
Dicionário R4DS (Cap. 3) ↔ SQL

          

            
              
Função no R4DSO que fazEquivalente SQL

            
            
              
filter()Filtra linhasWHERE

              
select()Escolhe colunasSELECT

              
arrange()Ordena linhasORDER BY

              
mutate()Cria nova colunaColuna calculada

              
summarize()Resume (média, soma)GROUP BY / AVG

            
          

        


        

          
O Pipe |> (leia como "ENTÃO")

          
# Exemplo do estilo R4DS Cap. 3 (pacote dplyr):
notas_rfb |>
  filter(acertos >= 8) |>
  mutate(taxa = acertos / total) |>
  select(materia, acertos, taxa)

          

            Nota: o pipe nativo |> funciona no R base também! Experimente depois no RStudio: c(10, 20, 30) |> mean().

Entendendo Recursão em 3 Passos

      
Recursão é uma função que chama a si mesma diminuindo o número até bater no freio (else return(0)).


      

        

          
Versão reduzida: lista(6)

          

            

              R ao vivo • tente prever antes de rodar!
              

                
                
              

            

            
            

          

        


        

          
Pense como uma escada (Ida e Volta)

          
    
            
  1. Ida (descendo de 3 em 3):
    lista(6) → lista(3) → lista(0) → lista(-3).
    2. 
            
  2. Freio (caso base):
    -3 > -3 é FALSE → entra no else e retorna 0.
    3. 
            
  3. Volta (somando e imprimindo):
              
      
                
    • lista(0): 0 + 0 = 0 → imprime 0
      • 
                
    • lista(3): 3 + 0 = 3 → imprime 3
      • 
                
    • lista(6): 6 + 3 = 9 → imprime 9
      • 
              
    
            
    4. 
          

        

      


      

        Ponto-chave: Como print(temp) vem depois da chamada recursiva, ele só imprime na volta — por isso sai 0, 3, 9!

Lógica de 3 Estados: ? (SQL) = NA (R)

      
A Q80 do seu PDF cobrou lógica de 3 estados (T, F, ?) em SQL — e no R o NA funciona exatamente igual!


      

        

          
Rodando a Q80 de SQL direto no R!

          

            

              R ao vivo • | = OR, & = AND, ! = NOT, NA = ?
              

                
                
              

            

            
            

          

          
          

            Saídas: I → TRUE  |  II → NA  |  III → NA.

            Gabarito Q80 (pág. 140): D (II e III, apenas)!
          

        


        

          
Por que NA | TRUE dá TRUE?

          
    
            
  • No OU (|), basta um lado ser verdadeiro para o resultado já ser TRUE — nem importa o que está escondido no NA!
    • 
            
  • Já no E (&), se um lado é TRUE e o outro é NA, não dá para saber → continua NA.
    • 
            
  • Teste também no editor ao lado: FALSE & NA (dá FALSE!).
    • 
          

        

      


      

        Por que mostrar isso? Conecta duas matérias de uma vez: ela entende o NA do R4DS Cap. 12 e já fixa a Q80 do PDF da Receita Federal!
