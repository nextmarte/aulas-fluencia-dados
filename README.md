# Aulas de R, Python e Fluência em Dados

Slides interativos e roteiros práticos para preparação do zero (foco: leitura e interpretação de código para concurso).

## Estrutura

- `index.html`: página inicial do portal publicada no GitHub Pages.
- `aulas/01-r-basico/index.html`: slides da Aula 1 (instalação R + RStudio, objetos `<-`, vetores `c()`, funções `mean()`, `sum()`, `length()` e desafio estilo prova), com base em [R para Ciência de Dados (pt-BR)](https://pt.r4ds.hadley.nz/).

## Como adicionar novas aulas

1. Crie uma pasta em `aulas/<numero-tema>/index.html`.
2. Adicione o card correspondente em `index.html`.
3. Faça `git add .`, `git commit` e `git push` para atualizar o GitHub Pages automaticamente.
